# 🍓 Glamour Minesweeper

**Гламурный сапёр с клубничками в шоколаде!**

🎮 **Играть сейчас:** https://mironchick.github.io/glamour-minesweeper/

---

## ✨ Особенности

- 🎀 **Розовый гламурный дизайн** в стиле Barbie-core
- 🍓 **Клубнички вместо мин** (обычные и в шоколаде)
- 🎯 **Два режима сложности:**
  - 🍓 **Базовый гламур** — 16×16, 40 мин
  - 💎 **Люксовый гламур** — 16×30, 99 мин
- 🎊 **Конфетти** при победе с надписью "Мур мур гламур"
- 😵 **Анимация поражения** с "Пу-пу-пу"
- ⚡ **Классическая механика** с двойным кликом (chord)
- ⏱️ **Таймер** и счётчик мин
- 🛡️ **Безопасный первый клик** — никогда не взорвёшься сразу

---

## 🎮 Как играть

1. **Левый клик** — открыть ячейку
2. **Правый клик** — поставить флажок 🍓
3. **Двойной клик** по цифре — автоматически открыть соседей (если все мины помечены флажками)
4. **Цель** — открыть все безопасные ячейки и не подорваться на клубничках в шоколаде

---

## 🛠️ Технологии

- HTML5
- CSS3 (градиенты, 3D-эффекты, анимации)
- TypeScript (логика игры)
- Canvas API (конфетти)
